# AI Recruitment Assistant v1.1 (AI Рекрутер)

Агент на базе искусственного интеллекта для автоматического анализа соответствия кандидатов (из сохраненных MHTML файлов HH.ru) описанию вакансии.

## 🚀 Возможности
- **Умный Парсинг**: Извлекает структурированные данные (Резюме и Вакансия) из MHTML файлов HH.ru.
- **AI Аналитика**: Использует LLM (GPT-4o/Claude) для скоринга кандидатов по шкале 0-100.
- **A/B Тестирование**: Поддержка переключения между разными движками парсинга и промптами.
- **Детальные Отчеты**: Генерация Markdown-отчетов с топом кандидатов, резервом и отсеянными.

## ⚖️ Сравнение Парсеров (Какой выбрать?)

В проекте реализовано два движка парсинга. Вы можете переключаться между ними при запуске.

| Характеристика | **Новый Парсер (Рекомендуется)** | **Старый Парсер (Legacy)** |
| :--- | :--- | :--- |
| **Аргумент CLI** | `--parser new` | `--parser old` |
| **Формат данных** | **JSON** (Структурированный объект) | **Markdown** (Сплошной текст) |
| **Точность** | Высокая. Разделяет навыки, опыт, график работы на отдельные поля. | Средняя. LLM сама пытается найти факты в тексте. |
| **Промпт** | `hr_expert_json.txt` (Строгая логика, математический подсчет опыта) | `hr_expert_legacy_markdown.txt` (Более "творческий" анализ) |
| **Для чего лучше** | Для точного матчмейкинга, проверки стека технологий, графика и локации. | Если структура HH.ru сильно изменится и JSON парсер сломается. |

## 🛠️ Установка
1.  **Склонируйте репозиторий**
2.  **Создайте виртуальное окружение**: `python -m venv .venv` и активируйте его.
3.  **Установите зависимости**: `pip install -r requirements.txt`
4.  **Настройка**:
    - Скопируйте `.env.example` в `.env`.
    - Установите `LLM_API_KEY` и `LLM_BASE_URL` (например, OpenRouter или OpenAI).

## 🏃 Использование
Поместите файлы MHTML (Резюме и Вакансии) в папку `resume vs vacancy`.

### Режим по умолчанию (Рекомендуемый)
Использует **Новый JSON Парсер** и **Продвинутый HR Промпт**.
```bash
python analyze_candidates.py
```
*(Эквивалентно: `python analyze_candidates.py --parser new --prompt hr_expert_json.txt`)*

### Старый режим (Legacy)
Использует **Старый Markdown Парсер** и **Старый Промпт**.
Используйте этот режим, если хотите вернуться к прежнему поведению.
```bash
python analyze_candidates.py --parser old
```

### Продвинутый режим - A/B Тестирование
Вы можете комбинировать парсеры и промпты для экспериментов:
```bash
# Использовать новый парсер, но старую логику промпта (не рекомендуется, но возможно)
python analyze_candidates.py --parser new --prompt hr_expert_legacy_markdown.txt

# Использовать свой кастомный промпт
python analyze_candidates.py --parser new --prompt my_custom_prompt.txt
```

## 📂 Структура Проекта

### Основное ядро
- `analyze_candidates.py`: Главный скрипт запуска.
- `hh_parser.py`: **[NEW]** Парсер на базе BeautifulSoup (извлекает JSON).
- `extract_mhtml.py`: Старый парсер / Вспомогательные утилиты.
- `config.py`: Загрузчик конфигурации.
- `models.py`: Pydantic схемы данных.
- `generate_report.py`: Генератор отчетов.
- `prompts/`:
    - `hr_expert_json.txt`: **[NEW]** Промпт для точного JSON-анализа.
    - `hr_expert_legacy_markdown.txt`: Оригинальный текстовый промпт.
